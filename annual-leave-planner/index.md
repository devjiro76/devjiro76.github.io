# 쉼표 황금연휴 플래너

공휴일과 주말 사이에 연차를 어디에 붙이면 가장 길게 쉬는지 계산해 주는 iPhone 앱입니다.

## 주요 기능
- 국가별 공휴일 기반 추천 휴가 구간 계산
- 가장 긴 연휴 / 효율 / 짧은 휴식 분산 전략 비교
- 추천 결과 공유
- 캘린더(.ics) 저장 또는 내보내기
