# 로또 관리 개인정보처리방침

로또 관리는 사용자가 직접 입력한 로또 번호와 확인 기록을 기기에서 관리하는 로컬 유틸리티 앱입니다.

## 기기에 저장되는 정보

- 사용자가 입력한 번호, 메모, 회차 정보와 확인 기록은 기기 내 저장소에만 보관됩니다.
- 개발자는 이 기록을 자체 서버로 전송하거나 계정과 연결하지 않습니다.

## 광고

- 무료 이용 중에는 Google AdMob 배너 광고가 표시될 수 있습니다.
- AdMob은 광고 제공, 분석 및 부정행위 방지를 위해 기기 식별자, IP 주소에서 추정한 대략적 위치, 광고 상호작용, 성능·진단 정보를 처리할 수 있습니다.
- 이 데이터 처리는 Google의 개인정보처리방침과 사용 중인 기기의 광고 개인정보 설정을 따릅니다.

## 결제

- 광고 제거 1회 구매는 Apple App Store를 통해 처리됩니다.
- 개발자는 결제 수단이나 결제 정보를 직접 수집하거나 저장하지 않습니다.

## 사용자 선택 및 문의

- 광고 제거 구매 후에는 배너 광고가 표시되지 않습니다.
- 기기에 저장된 기록은 앱의 삭제 기능 또는 앱 삭제로 제거할 수 있습니다.
